# YouTube Search — QA Automation Suite

## 📖 Overview
Automated test suite for **YouTube Search** functionality using Selenium WebDriver, Java, and TestNG. Validates search workflows, filter interactions, and video result validation on YouTube's platform.

---

## 🚀 Key Testing Highlights
- **Search Automation:** Validated keyword search returns relevant video results
- **Filter Testing:** Tested upload date, type, duration, and features filters
- **Sort Validation:** Verified sorting by relevance, upload date, view count, and rating
- **Negative Testing:** Handled empty search, special characters, and no-result scenarios
- **Dynamic Waits:** Handled YouTube's dynamic content loading with explicit waits

---

## 🛠️ Tech Stack
| Technology | Purpose |
|---|---|
| Java | Core language |
| Selenium WebDriver | Browser automation |
| TestNG | Test runner & assertions |
| Maven | Build & dependency management |

---

## ▶️ How to Run
```bash
git clone https://github.com/ritvikz/crio-youtube-search-qa.git
cd crio-youtube-search-qa
mvn test
```
